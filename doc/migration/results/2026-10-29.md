## 仍需解决

1. 当前 Pi 没有已验证的 pigpiod。此轮完成的是 Java socket 适配器，没有宣称 native 后端已可用。
2. 标准 pigpio PWM 会返回邻近频率；默认采样率下 300Hz 会落到 320Hz，默认零容差拒绝。需电机驱动规格确认允许偏差，或实现/选择另一 native 波形方案；不擅自改频率或接线。
3. 舵机实际 BCM 引脚、有效电平和方向仍需现场确认；示例配置未猜测这些值，设备默认不启用。
4. 真实画面、旧手机操作、30 分钟集成稳定性与波形精度均未验证。GPIO/摄像头代码已有实现，仍不能宣布整项迁移完成。

参考：[rpicam 官方文档](https://www.raspberrypi.com/documentation/accessories/camera-software.html)、[pigpio 官方协议及 PWM 频率表](https://github.com/joan2937/pigpio/blob/master/pigpio.py)。
