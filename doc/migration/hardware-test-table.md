## 连续采集指标

- JPEG：2,412～13,304 bytes，均小于单 UDP JPEG 上限 65,506 bytes。
- `sentFrames=2996` 包含 10 次启停的 10 帧和连续运行 2,986 帧；超长帧丢弃计数为 0。
- V4L2 源端 30fps，Java 主动选取最新帧约 5fps；主动取样不计入 `droppedFrames`，不能把这个 0 解读为源端每帧均传输。
- Java RSS 约 50.6～52.2 MiB，后段保持约 52.1 MiB；Java CPU 约占单核 6.1%。这些数值不包括 `v4l2-ctl` 子进程。
- 停止后采集子进程数为 0，TCP/UDP 端口释放。10 分钟测试版本为 `0.4.0-usb`；当前 `0.4.1-usb` 捕获逻辑相同，并另做局域网真实画面验证。
