# 小车与手机控制端使用说明

本文依据当前源码整理，主要覆盖 `app`（小车端）和 `app_mobile`（手机端）。未连接实车、未验证构建，实际硬件行为仍需上车核对。

## 1. 使用流程

启动小车端 → 手机填写小车 IP 和端口 8010 → 打开连接开关 → 等待 `Status:CONNECTED` → 点击 `Ctrl` 操控 → 点击 `preview` 查看画面。

| 模块 | 安装位置 | 作用 |
| --- | --- | --- |
| `app` | 小车 Android Things 主板 | 初始化硬件、接收控制指令、发送摄像头图像 |
| `app_mobile` | Android 手机 | 连接小车、控制运动和灯光、查看画面、调整摄像头舵机 |

小车端打开后基本是空白页面，这是当前设计。其 `MainActivity` 自动初始化 `DeviceManager`、绑定 `CameraService`，并启动 TCP 8010 服务，不需要在小车屏幕上点击控制按钮。

## 2. 使用前准备

- 小车需要 Android Things 外设运行环境。代码仅在 `Build.MODEL == "iot_rpi3"` 时初始化车轮、灯、蜂鸣器和舵机，普通 Android 手机不能直接替代主板。
- 手机和小车连接到可互通的同一局域网。程序没有自动发现、蓝牙配对或应用内配网功能。
- 从路由器设备列表等途径取得小车的局域网 IP。
- 确认电机驱动、外设供电和控制线连接正确。

### 硬件接口

以下 BCM 编号不是排针的物理序号，也不是完整接线图。

| 部件 | 代码使用的接口 |
| --- | --- |
| 左轮方向 | BCM21、BCM20 |
| 左轮速度 PWM | BCM16 |
| 右轮方向 | BCM26、BCM19 |
| 右轮速度 PWM | BCM13 |
| 前灯 R/G/B | BCM22、BCM27、BCM24 |
| 蜂鸣器 | BCM8 |
| 摄像头舵机 | `PWM0`，50 Hz |

舵机的物理接线需结合原板卡配置确认，代码只指定了 `PWM0`。

## 3. 构建、安装和启动

在项目根目录构建：

```bash
./gradlew :app:assembleDebug :app_mobile:assembleDebug
```

默认 APK 路径：

```text
app/build/outputs/apk/debug/app-debug.apk
app_mobile/build/outputs/apk/debug/app_mobile-debug.apk
```

用 `adb devices` 查看设备序列号，将下面的 `CAR_SERIAL` 和 `PHONE_SERIAL` 替换为实际值：

```bash
adb -s CAR_SERIAL install -r app/build/outputs/apk/debug/app-debug.apk
adb -s PHONE_SERIAL install -r app_mobile/build/outputs/apk/debug/app_mobile-debug.apk

adb -s CAR_SERIAL shell am start -n org.mark.thingshello/.MainActivity
adb -s PHONE_SERIAL shell am start -n org.mark.mobile/.MainActivity
```

以上命令是使用参考，本文整理时尚未执行构建或安装验证。

## 4. 手机连接小车

1. 打开手机端。
2. 在 `host ip address` 输入小车 IP，而不是手机 IP。
3. `port` 保持 **8010**。小车服务端写死为 8010，不能只修改手机端口。
4. 打开旁边的开关。
5. 等待日志出现 `Status:CONNECTED`。
6. 点击已启用的 `Ctrl` 按钮进入遥控页。

成功连接会保存 IP，下一次自动填入最近地址。如果小车 IP 改变，需要重新填写。

## 5. 遥控页操作

| 控件 | 功能与操作 |
| --- | --- |
| 顶部横向滑条 | 设置速度上限，范围 0～100，每次进入默认 40；不是实际车速单位 |
| 中间摇杆 | 上推前进、下推后退；左右通过左右轮速度差转向；推得越远速度越高 |
| `左转` / `右转` | 按住原地转向，松开或取消触摸时发送停车指令 |
| 顶部无文字复选框 | 前灯开关；开启时三个颜色通道均输出 100% |
| `preview` | 在中部区域打开小车摄像头画面 |
| 画面右侧竖向滑条 | 调整摄像头舵机位置，范围 0～100，不直接代表角度 |

### 速度调整

速度滑条本身不发送车轮指令，只影响后续摇杆或转向操作。因此，不要把“将速度滑条拖到 0”当成即时刹车。

### 舵机与车轮互斥

车轮和摄像头舵机通过 `ExclusiveBind` 互斥控制。调整舵机时会释放车轮驱动，之后再次操作车轮才会重新绑定。建议先停车，调整镜头后再继续行驶。

### 退出和停车

**当前没有实现手机断线自动停车。** 小车端的断线回调为空，手机退出遥控页也没有主动发送停车指令。

首次恢复使用时，应架空车轮验证停止动作。退出前先松开操作并确认停车，再返回连接页关闭连接开关，不能用断网代替停车。

## 6. 摄像头预览

点击 `preview` 后：

1. 手机通过 TCP 发送打开摄像头指令，指定 320×240。
2. 手机启动 UDP 接收。
3. 约 1 秒后向小车 UDP 8000 发送 `hello`，报告回传地址。
4. 小车回传图像，手机显示画面、累计流量等信息。

| 通信 | 用途 |
| --- | --- |
| 小车 TCP 8010 | 接收车轮、灯光、舵机、摄像头开关等指令 |
| 小车 UDP 8000 | 接收手机预览握手并回传图像 |
| 手机动态 UDP 端口 | 接收回传图像，无须手动填写 |

能控制车轮但没有画面时，应检查 UDP 通信、摄像头及权限，不能只检查 TCP。

离开预览所在页面会触发关闭摄像头指令。当前正常操作链路没有启用 AI 识别，也没有手机蜂鸣器按钮；蜂鸣器主要用于小车启动提示。

## 7. 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 无法连接，`Ctrl` 一直灰色 | 小车端是否启动、IP 是否正确、端口是否为 8010、局域网是否隔离客户端 |
| 已连接但所有硬件无反应 | 主板型号是否为 `iot_rpi3`，硬件初始化是否失败；TCP 连通不等于驱动初始化成功 |
| 只有车轮不动 | 电机供电、BCM 接线，查看 `Wheel` / `WheelAction` 日志 |
| 能驾驶但预览黑屏 | UDP 8000、摄像头连接及权限，查看 `DoorbellCamera` / `CameraService` 日志 |
| 切后台后画面不恢复 | 预览接收器存在生命周期隐患；可返回连接页，重新进入 `Ctrl` 并打开预览 |

小车 Manifest 中的 Android Things `uses-library` 声明目前被注释，而依赖使用 `compileOnly`。若小车启动报 Android Things 类找不到，应核对该声明及主板系统环境。
